Mini Shell in C

A Linux-based Mini Shell implemented in C to understand how a command-line shell works internally using process creation, system calls, signal handling, command parsing, built-in commands, foreground/background execution, and prompt customization.

Project Overview

This project implements a simplified Linux shell that continuously:

Displays a shell prompt.
Reads a command from the user.
Checks for special shell functionality such as PS1.
Identifies built-in or external commands.
Executes the command.
Manages foreground/background processes.
Returns to the prompt and waits for the next command.

The shell starts with the default prompt:

minishell$

The prompt can also be changed dynamically using:

PS1=MyShell$

After changing it:

MyShell$

Custom Prompt --- PS1
One of the implemented features is dynamic shell prompt modification.

The user can enter:

minishell$ PS1=myShell$
The shell updates the global prompt:

myShell$
The next command is then displayed using the new prompt:

myShell$ pwd
/home/user/minishell

myShell$ ls
...
Signal Handling
Signal handling is used for process control and terminal interactions.

Signals handled/used by the project include:

Signal Purpose

SIGINT Handles interrupt generated by Ctrl+C SIGTSTP Handles stopping of a foreground process SIGCHLD Indicates a child process state change

The shell uses signals together with process-management functions to control foreground and background jobs.

Important Linux APIs
Function / API Purpose

fork() Creates a child process execvp() / execve() 
Executes an external program 
waitpid() Waits for a child process 
chdir() Changes the working directory 
getcwd() Gets the current working directory 
kill() Sends a signal to a process signal() / signal-related handling Handles process signals 
getpid() Gets the current process ID
getenv() Retrieves environment variables 
exit() Terminates the shell

Key Challenges
Implementing command parsing and distinguishing different command types.
Managing parent and child processes using fork() and exec().
Handling foreground and background execution.
Maintaining a job list for background/stopped processes.
Implementing fg and bg using process signals and waitpid().
Handling terminal signals without unnecessarily terminating the shell.
Implementing dynamic prompt modification using the PS1= syntax.
Understanding how user-space shell programs interact with the Linux operating system through system calls.

Build and Run
Clone the repository:

git clone <repository-url>
cd Mini-Shell
Compile:

gcc *.c -o minishell
Run:

./minishell
The project is intended for a Linux/POSIX environment.
